The startup update prompt references the version checks, per-session dismissal and update details flow in [Spicy Lyrics' CheckForUpdates](https://github.com/iPixelGalaxy/spicy-lyrics/blob/dev/src/utils/version/CheckForUpdates.tsx) and UpdateDialog (AGPL-3.0). SpotiFlex uses its own dialog, signed release notes and native executable replacement. No upstream update source or assets are copied.

The native lyrics implementation references behavior and the provider wire format from [iPixelGalaxy/spicy-lyrics](https://github.com/iPixelGalaxy/spicy-lyrics), the Spicy Lyrics fork maintained by iPixelGalaxy and its upstream contributors. That project is published under AGPL-3.0. No upstream JavaScript runtime, logos, fonts, or artwork are bundled. The lyrics animator reimplements Spicy Lyrics' default animator in Rust and in the desktop frontend (`frontend/lyric-motion.ts`, `frontend/lyric-animator.ts`): word and letter scale, lift and glow curve points sampled with a natural cubic spline, spring tuning, held-letter proximity falloff, glow shadow radii and opacities, line opacities, text-shadow blur per line, the 20% gradient wipe edge, and the 45-second background layer geometry. No Spicy Lyrics source files are copied. The current wire compatibility version is 100.10.50; this does not imply full feature parity.

Space Gravity (`frontend/space-gravity.ts`, `frontend/space-gravity-lyrics.tsx`) ports the pixels-spicy-lyrics fork's `src/utils/Lyrics/SpaceGravity.ts` and its `main.css` rules (100.10.54, AGPL-3.0): the seeded drift and bounce model, physics constants, play-area, cover, dock and footer constraints, the window-movement kick, the word window sized from free area, natural-layout spawning with the golden-angle overlap search, presence fades, role opacities and the reduced-motion static layout. It is rewritten for SpotiFlex's React lyrics page. Experimental word sync (`frontend/word-sync.ts`) reimplements behaviour read from Spicy Lyrics release 100.10.52 (`src/utils/Lyrics/ExperimentalWordSync.ts`, AGPL-3.0): the letter-weighted word timing, bracketed backing-vocal split and speech-rate line-end trimming. The FNV-1a hash and the seeded random mixer follow the upstream functions. Spotify audio-analysis snapping was not ported because SpotiFlex cannot read Spotify's audio analysis. Static-lyrics timing is an independent text-and-duration estimate, informed by the static conversion flow reviewed in the local pixels-spicy-lyrics fork; its audio-analysis requirement is not used. Paragraphs are split into phrases before timing. Splitting Apple Music syllables that hold several words follows the fork's `SplitAppleMusicSyllableWords` (pixels-spicy-lyrics 100.10.54): whitespace and hyphen words, timed by letter weight, without CJK segmentation; its bracket-to-backing-vocal pass for Apple syllables is not ported. No additional upstream source or assets are copied.

Animator presets (`frontend/animator-tuning.ts`, `frontend/animator-settings.tsx`) reimplement the pixels-spicy-lyrics fork's `src/utils/Lyrics/Animator/Tuning.ts`, `Upstream.ts` and `AnimatorBehaviorPanel.tsx` (100.10.54, AGPL-3.0): parameter names, ranges, defaults, value cleaning, saved presets, Randomize, and the `SLP1:`/`SLAP1:` share-code formats, plus the Custom preset's idle scale and joined-syllable rule from `Shared.ts` and `Mixed.css`. The fork's Pixel preset is omitted. Unlike the fork, vertical strength scales only the rise, not the resting offset of unsung text, so strong settings no longer drop unsung words below sung ones. The code is rewritten for SpotiFlex's React settings and animator; no fork files are copied.

Gibberish, a Unique Word Filters choice (`frontend/gibberish.ts`, `frontend/gibberish-dictionary.ts`), is copied and adapted from the pixels-spicy-lyrics fork's `src/utils/Lyrics/GibberishTransform.ts` and `src/utils/Lyrics/Gibberish/Dictionary.ts` (iPixelGalaxy/spicy-lyrics commit a60aa34, AGPL-3.0). The dictionary's 2,113 entries are kept in order and applied one after another as in the fork; the phonetic rules, t/d + y blending and double-consonant joining are carried over as written, so output matches the fork's. SpotiFlex respells a word timed in several syllables as one word before sharing it over its syllables, reads curly apostrophes and accents as plain letters, and leaves words with no Latin letters unchanged.

Lyric sources (`src/lyric_sources.rs`) reimplement the Spicy Lyrics fork's source manager (`src/utils/Lyrics/ExternalSources.ts` and `Sources/*.ts`, AGPL-3.0): its six sources and default order, quality-first selection, Musixmatch's macro, richsync and subtitle parsing with the fork's public desktop token, Spotify color-lyrics parsing, LRCLIB, and the Netease proxy with credit-line filtering. No fork source files are copied.

Community-credit usernames (`src/provider.rs`) reimplement behaviour read from [iPixelGalaxy/EeveeSpotifyReincarnated](https://github.com/iPixelGalaxy/EeveeSpotifyReincarnated) (GPL-3.0; `LyricsContributorIdentity.swift`, `KaraokeProfileResolver.swift`): the public `ttml.getTTMLProfile` lookup on spicylyrics.org with its devalue-indexed input and output, and the rule that keeps a display name's casing only when it spells the username. Unlike EeveeSpotify, a failed lookup keeps the name from the lyrics metadata. The code is rewritten in Rust; no EeveeSpotify source is copied.

Playlist and interface behavior is informed by the feature descriptions of [iPixelGalaxy/spotify-plus](https://github.com/iPixelGalaxy/spotify-plus). Its repository does not declare a license in the metadata reviewed during setup. SpotiFlex does not copy or bundle its source or assets.

The Load TTML window (`frontend/load-ttml.tsx`) and its Persistent, Temporary and Session load modes, Reset TTML and saved-lyrics list (`src/lyrics.rs`) reimplement behaviour and layout read from the local pixels-spicy-lyrics fork (`UploadTTMLModal.tsx`, `LyricsManager`, AGPL-3.0). No upstream source or assets are copied.

The return-to-current-lyric button reimplements the rounded square and press feedback of the Spicy Lyrics fork's `ScrollToActiveLyric` control (`src/css/default.css`, AGPL-3.0), adapted to the requested album-tinted glass appearance with SpotiFlex's existing scroll behavior and Lucide chevrons. No upstream source or assets are copied.
