Home refreshes on entry, after native reconnection, and when the selected song changes while Home is visible. Cached shelves remain visible during refresh. Supported shelves include New release / Jump back in, Recents and Made For when supplied by Spotify. The opaque Home toolbar matches its panel when Liquid Glass is disabled.

Artist headers use a circular avatar on an artwork-colored gradient when a banner is unavailable. Both banner and avatar layouts place Spotify verification and compact monthly listener counts below the artist name, using the reported metadata.

Spotify's public Web API does not expose playlist folders. SpotiFlex reads and edits them through Spotify's own rootlist service. Creating, renaming and deleting folders and moving saved playlists use native changes, verified by a library re-read before success. Deletion removes only the selected folder's two markers: playlists and subfolders, including empty subfolders, move up one level. Missing, duplicate or reversed target markers are rejected before writing. Folder menus close when the account changes; an open destination picker follows library updates and disables the playlist's current folder. Unit checks parse the library after folder removal to verify preserved owned and collaborative playlists, nested folders and empty subfolders. Browser checks cover nested moves, moving back to the library root, deletion confirmation, keyboard focus, cancellation, backend failures, library updates and sign-out. These browser checks use a mocked desktop bridge; they do not establish live Spotify writes. Existing SpotiFlex-only local folders remain separate from Spotify folders. Library, playlist contents, saved items, play history and playlist edits go through the native librespot session, so the [2026 development-mode changes](https://developer.spotify.com/documentation/web-api/tutorials/february-2026-migration-guide) that limit the Web API to playlists the user owns or collaborates on apply to the optional developer connection. Native mode reports native failures without attempting the Web API. These internal services are undocumented and may change.

Controls for modifying Spotify's own web menus, Spicetify developer tools, and injected experimental-feature dialogs do not apply to this standalone client.

Explicit backward seeks still apply immediately. These checks do not establish audible playback quality on another computer.

Song selection, Next and Previous invalidate old queued samples immediately, before Spotify Connect responds. The next queued song preloads as soon as the current decoder is ready, and audio-output initialization overlaps connection setup. Ctrl + + (including Ctrl + = and numpad Add) increases interface zoom; Ctrl + - decreases it; Ctrl + 0 resets to 100%. Zoom persists across restarts, supports 75–200%, and works while a text field has focus.

Saved-song resume loads the queue and saved position in one native request. After audio sign-in, the saved track is prepared at that position without activating this device or starting playback. Late preparation cannot replace a playback selection. Play can still wait on Spotify when preparation has not finished.
